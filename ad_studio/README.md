# 无障碍音频描述配轨校审工具

面向音频描述(AD)制作的校审网页:在波形上排布描述卡、绑定旁白 PCM,自动核对
旁白时长 / 语速 / 对白重叠 / 关键声遮蔽 / 跨场景 / 相邻描述冲突,冲突处可循环试听
并比较「移动 / 缩写 / 局部压低原声」方案;**响度配平**解决不同录音棚分批补录导致的
听感忽大忽小(片段峰接近、有效 RMS 不同),框选有效语音后给出建议增益并按混音峰值
约束,原版 / 调整版 A/B 循环试听;修订留痕,确认版一键导出。

- 后端:Python 标准库(`wsgiref` 路由、`wave` 解析与混音、`sqlite3` 存项目/修订、`json`)
- 前端:原生 JavaScript + Web Audio API(试听/客户端混合预览)+ Canvas(波形时间轴)

## 启动

```bash
python3 server.py          # 默认 http://127.0.0.1:8000,PORT 环境变量可改
```

打开页面后点 **载入演示项目** 即可看到一套合成素材(雨夜场景,含对白提示音、
门铃/脚步关键声、4 段旁白),可立即体验拖拽、校审、循环试听与导出。

## 工作流

1. **载入素材**(左栏):正片 PCM WAV、旁白 WAV(多选)、四份 JSON 稿件
2. **排布**(中栏):在波形上拖动描述卡,或在卡片列表里绑定旁白、改时码、
   勾选「局部压低原声」「缩写稿」;「自动找空档」会把卡移到最近可容身的空档。
   「缩写稿」按目标语速把已绑定旁白 PCM 实际压缩(目标时长=字数÷目标语速,下限 0.8s),
   卡片时长、混合预览、仅旁白试听与导出 WAV 完全一致;未绑定的卡按语速缩短估算时长
3. **校审**(右栏):六类检查实时刷新;点 **循环试听** 反复听冲突区间,
   再点方案按钮(移到空档 / 局部压低 / 缩写稿 / 保留并记录)比较效果,可 ↩ 撤销
4. **修订留痕**:每条修订须填「素材摘要+时码」与「采用理由」,快照随修订入库
5. **响度配平**(中栏):见下节
6. **导出**(顶栏):描述脚本 TXT、混音 WAV(服务端 wave 渲染)、复演 JSON

## 响度配平(分批补录旁白)

同一段描述的旁白常由不同录音棚分批补录:片段峰值接近、有效语音 RMS 不同,直接
抬高增益又可能叠入原声后削波。配平面板按绑定旁白逐段处理:

1. 每段绘制 **20ms 窗短时 RMS(黄)与峰值(紫)曲线**,0 ~ −60 dBFS;绿线为目标电平、
   红线为峰值上限。开头静音、爆音尖峰、尾部接带噪声在曲线上一眼可辨
2. **在曲线上横向拖动框选有效语音**(可多段;Shift+拖或点空白新增,拖中间移动、
   拖两边改边界),排除静音/爆音/接带噪声;「整段」「清选区」重置
3. 左栏/面板顶部设置项目参数:目标电平(默认 −20 dBFS)、峰值上限(默认 −1 dBFS)、
   相邻跳变阈值(3 dB)、有效语音最短时长(0.3s)、增益范围(−14 ~ +15.6 dB)
4. 后端按选区计算:有效时长、RMS/峰值、**建议增益**(收敛到目标 RMS,再按混音峰值
   上限回退,并夹在增益范围内)、**叠入原声后的混音峰值**(服务端按完整混音模拟)、
   与上一描述的**响度跳变**(按混音实际生效增益)
5. 拖增益滑块(即时不打断拖动)或点「套建议」;**A 原版 / B 调整版**对选区循环试听
   (Web Audio GainNode,不渲染整段),■ 停止
6. 「确认」入修订(有效区间、增益;阻塞段可填人工留痕理由,但只作记录)。「全部确认」
   只确认无阻塞片段

阻塞错误(**该片段无条件保持 pending,人工理由不改变阻塞状态,增益不进混音/脚本/复演**),
均给出片段与时码定位:

| 错误 | 判定 |
|---|---|
| 通道格式不一致 | 旁白片段声道/采样率与正片工程不同,无法可靠叠加 |
| 有效语音不足 | 选区总时长 < 最短阈值(默认 0.3s)或选区为空 |
| 增益越界 | 人工增益超出允许 dB 范围 |
| 混音削波 | 完整混音中该片段选区内峰值超过上限,或 >0 dBFS 硬削波;报告成片时码、片段内时码与越界采样数 |

阻塞片段填了人工理由并点确认时:理由与草稿增益写入修订(摘要为「响度配平保持待处理」),
但状态仍为 pending。方案保存、确认、混音渲染与脚本/复演导出三处都会按实时校审结果
再次纠正状态(纵深防御),即便数据库里残留 confirmed 标记,阻塞增益也不会进入确认版输出。
只有修正选区/格式/增益使阻塞消除后重新确认,增益才会生效。

相邻响度跳变超阈值为**警告**(非阻塞),在校审栏显示,点「去响度配平」可定位到该段。
只有 `confirmed` 段的增益参与混音 WAV 渲染与脚本/复演导出,确认后混合预览同步生效。

## 稿件 JSON 格式

时码支持 `秒数` / `MM:SS.mmm` / `HH:MM:SS,mmm`。

```jsonc
// 对白稿
[{"start": 4, "end": 7.5, "speaker": "林", "text": "外面还在下雨吗？"}]
// 场景切点
[{"time": 15, "label": "场2 门厅·夜"}]
// 描述稿
[{"start": 0.6, "text": "雨夜,老式公寓客厅,台灯昏黄。"}]
// 关键声: maskable=false 为不可遮盖(门铃/脚步),true 为可让位环境声
[{"start": 19.9, "end": 21.0, "label": "门铃", "maskable": false}]
```

## 校审规则(参数左栏可调)

| 检查 | 规则 |
|---|---|
| 语速 | 描述字数 / 旁白时长 > 目标语速(默认 5.5 字/s) |
| 对白重叠 | 旁白区间与对白区间交叠 > 0.05s(压低原声后降级为提醒) |
| 关键声遮蔽 | 旁白与 `maskable:false` 关键声交叠 > 0.03s |
| 旁白时长 | 绑定片段长度超出当前空档(到下一对白/片尾) |
| 跨场景 | 旁白区间跨过场景切点 |
| 相邻描述 | 两描述间隔 < 最小间隔(默认 0.4s)或互相重叠 |

## 导出物

- **描述脚本** `ad_script.txt`:时码区间 + 文本 + 旁白素材/时长/压低标记 +
  各段响度配平状态(确认增益/有效区间/人工保留理由)+ 修订记录
- **混音 WAV** `ad_mix.wav`:服务端按 placements 渲染,压低段 0.15s 斜坡、增益可调;
  仅采用 `confirmed` 配平增益;响应同时返回削波采样数/峰值/首次时码
- **复演 JSON** `ad_replay.json`:项目全部素材摘要、placements、参数与**确认版响度
  配平方案**,可重新导入复演

数据存于 `data/app.db` 与 `data/<项目id>/`(WAV 文件)。
